## Dependencies

- Neovim >= 0.9.4
- [lazy.nvim](https://github.com/folke/lazy.nvim)
- [Ghostty](https://ghostty.org/) (or another Kitty Graphics Protocol terminal)
- [chafa](https://hpjansson.org/chafa/)
  ```bash
  sudo dnf install chafa   # Fedora
  sudo apt install chafa   # Debian/Ubuntu
  ```
- A [Nerd Font](https://www.nerdfonts.com/)

## Installation

```bash
git clone https://github.com/MamitianaAntonio/kuronio-nvim.git ~/.config/nvim
nvim
```
